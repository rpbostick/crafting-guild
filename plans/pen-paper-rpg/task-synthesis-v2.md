## Standing rules from the review
- **Remix is the default power level ("more heroic"); Classic WoD is the optional.** Flip every place v1 made Classic the default (power scaling, damage, abilities that scale with HD such as Slay, Backstab, Volley, quicksilver and magic damage). Where a value differs between the two, give the default and the optional side by side in one consistent notation (e.g. "+HD (Classic: +2)"); the notes ask for a conversion table: add one section that lists every such value in both modes.
- **Don't reference Remix as a book inside rules text** for mechanics the game now owns (see the Summon note); attribution goes in credits and in the sections the notes name (Zeal: "from *World of Dungeons: Remix* by Tam H." with a proper credit line), and in source blocks.
- Accepted proposals stay as written unless a note asks for changes. Rejected proposals get a new proposal that follows the note on them, or, where the note only asks for discussion, a fresh discussion block with options and a provisional proposal clearly marked as such.
