## Requirements (Patrick, 2026-10-01)
- A private fan rules text for running games in *The Painted Wastelands*, built from *World of Dungeons* 1979 (WoD), *World of Dungeons: Remix* (Remix) and *Advanced World of Dungeons* (AWoD).
- v1: merge all three texts into one document, sections in a logical order, every passage tagged with its game. Keep most of the information from each; where classes, skills or abilities differ, keep all of them, creating new classes if needed. Names to be discussed with Patrick.
- Show it as a side-by-side diff tool: sections with suggested changes highlighted, an Accept button per suggestion, and the discussion of contradictions.
- Keep original text and art in the private project. Licence information for each source, so the eventual public game knows what it may use and what it must rewrite.
- v2 (later): *Electric Bastionland* rules that differ, its spells, oddities and equipment; Failed Careers in the character generator, keeping WoD's gameplay; *The Painted Wastelands* (PDF to come). Research how the Into the Odd / Electric Bastionland engine is licensed for derivatives (Cairn and others).

## Steps
1. **Licences** (`task-licences.md`, research, parallel with 2). Output `docs/research/licences.md`.
2. **Synthesis** (`task-synthesis.md`). Output `rules/v1/synthesis.md` in the block format below, plus `tests/synthesis.test.js` checking the format.
3. **Diff tool** (`task-diff-tool.md`, after 2, gate: Patrick previews on :8801). Static page in `site/`, parser tested with `node --test`.
4. **Publish** (after 1 and 3): Patrick decides on GitHub Pages with the licence report and release audit in hand.
5. Patrick reviews suggestions and names; accepted decisions are committed (`rules/v1/decisions.json`) and a clean merged text is generated from them.

## Block format (shared by steps 2 and 3)
`rules/v1/synthesis.md`: `#` title, `##` sections, optional `###` subsections. Inside sections, fenced blocks:
```
::: source wod p1
verbatim text
:::
::: proposal id=classes-fighter
proposed merged text (Markdown)
:::
::: discussion id=classes-fighter
why; what contradicts; options
:::
```
Sources: `wod`, `remix`, `awod`, with the PDF page. Every proposal has a discussion with the same id; ids are unique.
