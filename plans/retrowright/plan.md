## Direction (Patrick, 2026-10-12)
- Finish retrowright: a nice browser experience for players, SNES and GBA as well as NES, and a toolkit for the REA ROM work (memory viewer and RAM search, tile/palette/map viewers, trace and breakpoints, patch maker and applier). Thorough research for usable software before each of these.
- The goal behind it: pull apart games in ROMs with REA, then build our own games from existing ones (example: Super Mario Bros. remade with Skate or Die / Tony Hawk's Pro Skater mechanics). Remakes start as ROM hacks shared as patches on the player's own ROM; a remake published on its own gets our own art and code.
- Cores: permissive licences only (MIT, BSD, ISC, zlib, Apache-2.0, MPL-2.0). Patrick suggested reverse-engineering GPL emulators with REA if needed; told him a rewrite from GPL code is still derived unless strictly clean-room, so the sources are hardware documentation and permissive projects.
- Clean room, if a GPL emulator's knowledge is needed (asked 2026-10-12): running GPL programs and comparing results (as with MesenCE) is fine at any time. Reading their code happens only in a separate spec builder, which writes behaviour (timings, register effects, edge cases) in its own words, with no code. The core builder sees only that spec, the hardware documents and the comparison results, and the task logs record what each one read. Not legal advice: before anything earns money, a lawyer looks at it.

## Requirements (Patrick, 2026-10-10)
- A browser-based retro game emulator, run from a static demo page like the other demos (rpbostick.github.io/retrowright/), React.
- NES first: Final Fantasy and the other NES titles in `roms/` (local, git-ignored, copied from rea-roms-test's research files).
- Both, in stages: a proven core first (jsnes, chosen without a comparison spike), then parts replaced by our own code over time, each checked against the core.
- Games: the user loads their own ROM (kept in the browser, never uploaded). Later: our own rebuilt ROMs (from the rea-roms-test work) and homebrew ROMs.
- Repo: private `rpbostick/retrowright-dev` now; a public `rpbostick/retrowright` at the first release, through `release-audit.md` and Patrick's approval. MIT, crediting jsnes (Apache-2.0).
