# The site's React Bits backgrounds come from reactbits-kit

The site's three React Bits components (`src/reactbits/{Waves,Aurora,Iridescence}/`, change list `src/reactbits/LICENSE.md`) and our modules (`src/shared/{momentum,rippleField,clothFollow,sphereSpin}.ts`) now live in **reactbits-kit**, public at `github:rpbostick/reactbits-kit#v0.3.0` (MIT; it contains no React Bits code; README there). `rbx add <Component> --profile site` regenerates our customized components from upstream React Bits at a pinned commit; the package exports the modules and a React adapter.

## Behaviour
- Add the kit as a dev dependency (`npm install -D github:rpbostick/reactbits-kit#v0.3.0`) and a `reactbits-kit.json` (components, `site` profile, pinned upstream).
- Regenerate `src/reactbits/{Waves,Aurora,Iridescence}/` with `npx rbx add … --profile site --to src/reactbits` (committed, as React Bits allows inside a website); each gets the kit's `CHANGES.md`; `src/reactbits/LICENSE.md` keeps the React Bits licence text and points to the per-component change lists instead of repeating them.
- Import `momentum`, `rippleField`, `clothFollow`, `sphereSpin` from the kit (delete the local copies) and use the kit's adapter where it shortens the Hero wiring without changing behaviour.
- `npm run lint` (or a check script the build runs) includes `npx rbx check` so drift from the kit fails the build.
- Behaviour on every page is unchanged: figurewright's drag-only ripple, swirl, sheet glide, ball spin 0.1 and pattern drift; skywright's Aurora and colorwright's Iridescence backdrops.
- GitHub Actions builds the site with the kit installed from the public repo (the `prepare` script compiles it during `npm ci`; make sure the workflow does not pass `--ignore-scripts`).

## Tests
The existing check scripts (`check-hero-controls`, `check-sphere-spin`, `check-cloth-follow`, `check-momentum`, `check-ripple-field` or their kit equivalents) pass; `rbx check` passes; `npm run build` and `npm run lint` pass.
